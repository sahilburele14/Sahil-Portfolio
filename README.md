A personal portfolio showcasing my projects, skills, and experience as a Full Stack Developer.  
Built with modern web technologies and deployed on [Vercel](https://sahil-portfolio-ivory-two.vercel.app/) for fast, reliable hosting.

---

## 🚀 Features
- Responsive design optimized for desktop and mobile
- Built with **React + TypeScript** and **Vite**
- Smooth navigation and modern UI
- GitHub Actions workflow for automated deployment
- Hosted on Vercel for reliable performance

---

## 🛠️ Tech Stack
- **Frontend:** React.js, TypeScript, Vite
- **Styling:** CSS3, Tailwind/Custom styles
- **Deployment:** Vercel, GitHub Actions
- **Version Control:** Git & GitHub
